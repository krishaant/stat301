# STAT 301 Group Project

Group project for STAT 301 (2025SS), analyzing the [Customer Personality Analysis](https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis/data) dataset from Kaggle — customer demographics, spending habits, and campaign response for a retail marketing dataset.

**Group 4:** Krishaant Pathmanathan, Crystal Zhao, Yifei Shi

## Contents

- `FinalGroupProj.ipynb` — full analysis: data cleaning, EDA, and modeling
- `CrystalindividualPlanning.ipynb` — individual planning notebook

Covers data cleaning and tidying (handling missing income values), exploring customer demographics and spending categories, and modeling customer segments and campaign response.
